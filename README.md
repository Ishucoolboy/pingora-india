# Pingora — India Chat App

**Tagline:** Every connection starts with a conversation.

Pingora is an early, mobile-first prototype for an India-focused messaging and social app.

## Included in this first version
- Responsive chat-list interface and search
- Stories preview
- Bottom navigation for Chats, Contacts, Moments, and Me
- Installable web-app manifest and a basic service-worker shell
- Custom SVG app icon

## Run it
Open `index.html` in a browser. For Progressive Web App features, use HTTPS or a local development server.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site; GitHub will show the live URL in Pages settings.

## Important
This is a frontend demo only. The names and conversations shown are fictional sample data; messages do not reach real users. Authentication, secure storage, access controls, privacy disclosures, and abuse protections must be implemented before inviting real users or collecting personal information.
